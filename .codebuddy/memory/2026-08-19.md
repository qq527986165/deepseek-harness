## 用户问题：`dsh` 命令找不到
- 用户直接敲 `dsh plugin --profile web add dshmarket` 报 CommandNotFoundException。
- 原因：`dsh` 不是全局命令，是仓库根 package.json 的 script（`"dsh": "node --import tsx/esm apps/cli/src/bin.ts"`），且用户不在仓库目录。
- 正确用法：在仓库根目录 `cd e:\work\ProjectSet\deepseek-harness` 后运行 `pnpm dsh plugin --profile web add dshmarket`。
- 机制要点：`dsh plugin --profile <name> <args>` 将参数原样转发给 pnpm（apps/cli/src/plugin.ts，Windows 下经 shell 启动 pnpm.cmd）；安装后通过包 manifest 的 `dsh.bundle.patch` 判定是否加入 profile 层栈；找不到 pnpm 时返回 127。
